\# Data Instructions



This project uses 2024 NYC Yellow Taxi and Citi Bike trip data.



\## Data Sources



\- \*\*Yellow Taxi:\*\* NYC Taxi \& Limousine Commission (TLC) trip record data — https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page

\- \*\*Citi Bike:\*\* Citi Bike System Data — https://citibikenyc.com/system-data



\## Data Preparation



The project uses a sample of 10,000 trips per month for each transportation mode.



\- Yellow Taxi: 120,000 trips

\- Citi Bike: 120,000 trips



Download the relevant 2024 monthly files and place the raw data in this folder before running the notebook.



Raw datasets are not included in this repository because of their size. The notebook handles loading and preparing the data for the database pipeline.
